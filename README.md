# Solana Subaccount Viewer

A lightweight web app to connect a Solana wallet and view associated subaccounts, balances, and perpetual positions. Built with **Next.js**, **Tailwind CSS**, **Zustand**, and **Solana Wallet Adapter**.

## Features

- 🔐 **Connect Solana Wallet** using Solana Wallet Adapter
- 📂 **View Subaccounts** linked to the connected wallet
- 💰 **Check Balances** for each subaccount
- 📈 **Track Perpetual Positions** (perps) with live data
- 🔍 **Input Any Wallet** to inspect its subaccount data

## Tech Stack

- **Next.js** – React Framework
- **Tailwind CSS** – Utility-first styling
- **Zustand** – Lightweight state management
- **Solana Wallet Adapter** – Wallet integration
- **Drift SDK** – Access Drift protocol data on Solana
